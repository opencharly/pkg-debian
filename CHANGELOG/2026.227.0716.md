# 2026.227.0716 — docs: adopt the Agent-in-the-Loop Factory tagline

The product positioning line changed. OpenCharly is now **The Agent-in-the-Loop
Factory**, and the tagline sentence is "the fully equipped factory floor for you
and your agents". `debian/control` still described charly by its oldest wording,
"OpenCharly container management CLI", in the field `apt show opencharly` puts
in front of a user:

- The `Description:` synopsis is now "OpenCharly CLI — the fully equipped
  factory floor for you and your agents".
- Its extended-description continuation now opens "Compose, build, deploy, and
  evaluate boxes from a library of fully configurable candies" — `evaluate`
  replaces `manage`, matching how the project now describes itself. The rest of
  the paragraph is unchanged, including the standing note that Tailscale is
  deliberately not a dependency here (it is not in Debian main; the charly candy
  supplies it via the tailscale apt repo).

Description text only. No `Depends:`, `Suggests:`, or `Build-Depends:` entry is
touched — the superproject's `charly/packaging_test.go` greps this control file
for dependency parity against the embedded packaging section, and that parity is
unchanged.

Deb822 syntax re-verified after the edit: the file is valid UTF-8, every
extended-description continuation line begins with exactly one space, none is
tab-indented, and none carries trailing whitespace.
